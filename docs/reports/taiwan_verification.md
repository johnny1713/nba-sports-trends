# 台灣運彩盤口：人工抽樣驗證

玩運彩抓取器只讀「運彩盤」欄位（`td-bank-*`），但**在人工確認之前，所有抓到的盤口一律標記為未驗證**，
網站上會寫「台灣盤口未驗證」。驗證方式：用運彩官網或 App 查同一場次編號，逐欄比對。

雲端與 GitHub Actions 都連不到運彩官網（海外 IP 會被擋，403），所以這一步只能由你在台灣比對。
